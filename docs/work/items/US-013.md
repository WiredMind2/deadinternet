### US-013: Tell the operator when copying the tracking link failed
**As an** operator, **I want** a visible message when the clipboard copy fails **so that** I know to select the link text by hand.
**Points:** 1
**Status:** Done
**Acceptance criteria:**
- [x] Given the clipboard is unavailable, when I press Copy on a tracking link, then a message says the copy failed and the link is still shown
- [x] Given the clipboard works, when I press Copy, then the button says Copied and no failure message appears
