### US-011: Send affiliate clicks to a real, operator-set offer URL
**As an** operator, **I want** an affiliate tracking link to redirect to a URL I configured, and never to a fabricated domain **so that** recorded clicks mean real intent.
**Points:** 5
**Status:** Done
**Acceptance criteria:**
- [x] Given an affiliate experiment for merchant `acme`, when I save offer `acme` with url `https://acme.test/deal` via `POST /offers`, then `GET /r/{code}` redirects there and counts the click
- [x] Given an affiliate experiment whose merchant has no stored URL, when `GET /r/{code}` is hit, then the response is 404 naming the merchant and no click is counted
- [x] Given an offer row with a saved URL, when a later experiment remembers the same merchant, then the saved URL is preserved
- [x] Given any flow, when offers are remembered or listed, then no `example.test` URL is invented by the app
- [x] Given the Catalog screen, when I enter a merchant and URL and press Save offer URL, then the offer is saved and confirmed on screen
