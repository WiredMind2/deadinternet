### US-032: Faceless stills render speaks each beat
**As an** operator, **I want** the faceless renderer to voice each beat's `spoken` line **so that** the file is worth posting and scoring (today `render/faceless.py` writes a silent black screen with no audio).
**Points:** 5
**Status:** Done
**Acceptance criteria:**
- [x] Given a storyboard with N beats, when the faceless render runs, then each beat's `spoken` text becomes its own audio segment — the stills path reads the approved board (the API hands the renderer the storyboard's own directory), calls the injected speaker once per beat with `beat.spoken`, writes one `{id}.stills/NNN.audio` per beat, and muxes one aac stream into each per-beat segment before the concat joins them (`_stills_commands`/`_beat_command`, render/faceless.py; the speaker is the new injectable parameter on `render()` and `render_faceless()`); pinned by `test_stills_render_speaks_each_beat` and `test_stills_concat_listing_names_beat_segments_in_order` (tests/test_faceless.py), with the audio muxed end-to-end by `test_stills_render_length_is_the_sum_of_segments_with_real_ffmpeg` (real ffmpeg + real ffprobe, ran on this machine, not skipped). The default speaker is env-gated exactly like the avatar provider: `env_speaker` raises "TTS is not configured (DEADINTERNET_TTS_API_KEY)" without the key and "TTS provider call is not configured" with it — pinned by `test_env_speaker_refuses_without_a_key`, `test_env_speaker_still_refuses_with_a_key` (tests/test_faceless.py) and `test_live_faceless_render_fails_without_tts` (tests/test_edges.py, mirroring `test_live_avatar_render_fails_without_a_provider`); a real provider is injected through the same `speaker` parameter the tests use, and no network call happens while unconfigured.
- [x] Given the rendered file, when it is probed, then the video length is the sum of the segment lengths (± a small tolerance) — each beat's lavfi visual carries `d=` and `-t` equal to its own audio duration (never `length_sec`), and the concat sums them; verified with real ffmpeg + real ffprobe on this machine by `test_stills_render_length_is_the_sum_of_segments_with_real_ffmpeg` (1.0s + 1.5s wavs → probed 2.52s, tolerance 0.25; the ≈0.02s overshoot is aac priming). Durations come from the wav bytes themselves (stdlib `wave`), with an ffprobe fallback for non-wav segments (`test_non_wav_audio_is_measured_by_ffprobe`, `test_unmeasurable_audio_marks_render_failed`, tests/test_faceless.py).
- [x] Given platform_payout money on TikTok, when a draft would render under the 60-second Creator Rewards rule, then the length guard still applies before render — untouched: `_guard_length` still refuses at creation and acceptance (api/app.py, not modified here) and `approve` still raises `IneligibleLength`; the render adds no second guard now that length is derived from the spoken segments, so the creation-time rule stays the sole authority; pinned by the existing `test_short_tiktok_draft_is_refused_and_catalog_records_ids`, `test_tiktok_rewards_under_a_minute_cannot_be_approved` (tests/test_api.py) and `test_tiktok_rewards_shorter_than_a_minute_cannot_be_approved` (tests/test_transitions.py).
- [x] Given a TTS or mux failure, when render runs, then the experiment lands in `render_failed` with a reason (not a silent success and not a stuck `rendering`) — a speaker, probe or ffmpeg failure inside the build/run phases is caught and recorded, and nothing half-rendered is reported as success; pinned by `test_tts_failure_marks_render_failed`, `test_unconfigured_tts_marks_render_failed`, `test_unmeasurable_audio_marks_render_failed`, `test_stills_without_a_storyboard_marks_render_failed`, `test_empty_storyboard_marks_render_failed`, `test_runner_exception_marks_render_failed` and `test_wedged_ffmpeg_times_out_to_render_failed` (tests/test_faceless.py), plus the live path `test_live_faceless_render_fails_without_tts` (tests/test_edges.py); the API layer's mapping of a crashing renderer to `render_failed` is pre-pinned by `test_a_crashing_renderer_lands_in_render_failed_not_rendering` (tests/test_api.py).
