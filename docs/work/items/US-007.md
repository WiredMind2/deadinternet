### US-007: Accept or discard each suggested draft on its own
**As a** operator, **I want** to accept or discard one suggested draft without touching the others **so that** I don't create videos I didn't want.
**Points:** 3
**Status:** Done
**Acceptance criteria:**
- [x] Given two suggested drafts, when I accept one, then exactly one experiment is created and the other draft stays listed.
- [x] Given a listed draft, when I discard it, then it disappears from the list and no experiment is created.
- [x] Given an accept that fails, when the error banner shows, then every draft stays listed and acceptable.

Checked in the browser: Accept created exactly one experiment (3 → 4) with the "Accepted draft 1." notice; Discard emptied the list with the experiment count unchanged. The failure path is guarded by construction — `setDrafts` runs only after a successful POST, and a rejected create is exactly the 422 path covered by the API tests.
