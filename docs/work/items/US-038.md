### US-038: Snapshots honest about gaps
**As an** operator, **I want** blank snapshot fields stored as absent, not as zero **so that** "not measured" never masquerades as "measured zero" in the trend (today the dashboard sends 0 for every field left blank, and percent viewed shows 0%).
**Points:** 2
**Status:** Ready
**Acceptance criteria:**
- [ ] Given the Record snapshot form, when a field is left blank, then the stored snapshot keeps it absent (null), and a blank on the wire is not coerced to 0
- [ ] Given SnapshotHistory, when a field is absent, then the cell reads "—" rather than 0
- [ ] Given percent viewed, when views or watch time is absent, then the cell reads "—" rather than 0%
- [ ] Given a backdated `captured_at`, when snapshots are read back, then the order follows captured_at (folded into the Wave 2 landing: verify before starting)
