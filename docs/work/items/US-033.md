### US-033: Burned-in captions from beat on-screen text
**As an** operator, **I want** each beat's `on_screen` text burned into its time span, styled by `caption_style` **so that** a rendered file can carry captions the platforms recommend (synthesis: captions are a factor, not a default).
**Points:** 3
**Status:** Done
**Acceptance criteria:**
- [x] Given a beat with `on_screen` text, when its segment renders, then the text is drawn for exactly that beat's time span — the caption is a `drawtext` filter inside that beat's own segment command, whose `-t` equals its audio span, so the text cannot outlive its beat (`_beat_command`/`_caption_filter`, render/faceless.py); the on-screen line is passed via `textfile` + `expansion=none` so apostrophes, colons and percents need no filtergraph quoting; pinned by `test_on_screen_text_is_burned_into_its_own_beat` (tests/test_faceless.py) and, with real ffmpeg on this machine (ran, not skipped), by `test_captions_are_burned_into_their_own_beat_with_real_ffmpeg`: a raw gray frame inside beat one carries drawn pixels from a caption containing `It's 100%: the 'quoted' text`.
- [x] Given a beat with empty `on_screen`, when its segment renders, then no caption track is drawn — no caption file is written and no `drawtext` appears in that beat's filter chain; pinned by `test_on_screen_text_is_burned_into_its_own_beat` (asserts `002.caption.txt` is never created) and by the real-ffmpeg test above (the frame inside beat two is pure black).
- [x] Given `caption_style` on the experiment (e.g. "bold"), when captions render, then the style changes the draw, so a caption-style experiment remains a deliberate factor change — the value flows from `experiment.style.caption_style` into the filter with no global toggle: "bold" (the only value the domain names today, domain/rank.py) draws `fontsize=96:borderw=6` from the bold font candidates, any other value keeps `fontsize=72:borderw=3` and the default candidates; pinned by `test_caption_style_bold_changes_the_draw`, `test_caption_font_follows_the_style_candidates`, `test_caption_font_env_override_is_honoured` and `test_missing_caption_font_marks_render_failed` (tests/test_faceless.py) — a machine with no font fails with a reason naming `DEADINTERNET_CAPTION_FONT`, never a silent caption drop.
