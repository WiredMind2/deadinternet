### US-022: Dashboard error and state hygiene
**As an** operator, **I want** errors visible everywhere they matter and UI state that stays coherent **so that** no screen shows a misleading empty state or stale data.
**Points:** 3
**Status:** Done
**Acceptance criteria:**
- [x] Given a failed experiments load, when I am on Review or Post, then the real load error is shown (today only Board shows it; the others claim there is nothing in review)
- [x] Given an error banner raised while acting on experiment A, when I select experiment B, then the banner clears
- [x] Given the storyboard editor is still fetching, when the panel renders, then it shows a loading state rather than "Add a beat before approving this board."
- [x] Given two overlapping experiment reloads, when the older response resolves last, then it does not overwrite the newer list
- [x] Given Enter is pressed in any Catalog input outside the starter fieldset, then the starter-grid build is not triggered
