### US-031: Accepted drafts keep their parent and factor list
**As an** operator, **I want** every accepted draft to store which experiment it came from and the one factor it changed **so that** results can name the factor that moved, and decision 4 of research/synthesis.md ("keep the factor list on the proposal") holds after acceptance, not just on the proposal screen.
**Points:** 3
**Status:** Done
**Acceptance criteria:**
- [x] Given a draft accepted from the Proposals panel, when it is stored, then `parent_ids` and `factor_diffs` persist on the experiment (today `draftPayload` drops both and `ExperimentIn` has no fields for them) — `draftPayload` forwards both (web/src/App.jsx), `ExperimentIn` accepts them, the `experiments` table gains `parent_ids_json`/`factor_diffs_json` with a startup migration for legacy rows (`_ensure_lineage`, store/db.py), and insert/save round-trip them; pinned by `test_an_accepted_draft_keeps_its_parent_and_derived_factor_list` (tests/test_api.py), `test_lineage_round_trips_through_insert_and_save` and `test_legacy_rows_upgrade_with_empty_lineage` (tests/test_store.py), and the end-to-end accept in `test_flow_from_starter_grid_to_a_draft_proposal` (tests/test_flow.py). Unknown parents are refused with a 422 naming them and nothing is written (`test_an_unknown_parent_is_refused_with_nothing_written`, tests/test_api.py).
- [x] Given a stored factor list, when it is written, then it comes from `changed_factors` on the server, not from what the model declared (the declared list is never checked today) — `_lineage` (api/app.py) rebuilds a DraftSpec from the accepted body and stores only the diffs recomputed against each stored parent; the declared list is advisory and never written (a child's own tracking code reads as no money change because the diff compares the money path, not the code); pinned by `test_a_declared_factor_list_is_advisory_only`, `test_derived_diffs_name_every_moved_factor` (tests/test_api.py), and the flow test asserting the stored values replace the declared short forms.
- [x] Given Results, when a row has recorded diffs, then it shows "changed: style" (or the real factor) next to its cell — `_experiment_json` returns `parent_ids` and `factor_diffs`, pinned by `test_results_carry_lineage_for_rows_with_diffs` (tests/test_api.py); the Results article renders `changed: <fields>` from the payload (web/src/App.jsx, verified by `npm run build` — the dashboard has no component test harness, like the other dashboard stories).
- [x] Given a submitted draft with `parent_ids=[]`, when `_evaluate` runs, then it is refused (folded into the Wave 2 landing: this criterion may already be Done — verify before starting) — already Done by Wave 2: `_evaluate` refuses a parentless draft outright (propose/agent.py, "a draft needs a parent"), pinned by `test_a_parentless_draft_is_refused` (tests/test_proposer.py).
