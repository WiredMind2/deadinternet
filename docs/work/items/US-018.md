### US-018: Renders finish or fail on their own
**As an** operator, **I want** every render to end in success or render_failed within a bounded time **so that** no wedged ffmpeg hangs the API and no look style is a dead end.
**Points:** 5
**Status:** Done
**Acceptance criteria:**
- [x] Given an ffmpeg invocation that never exits, when a render runs, then it fails after a bounded timeout and the experiment is marked render_failed (today `subprocess.run` has no timeout and hangs a worker thread forever)
- [x] Given an experiment with `Look.kind == "clips"`, when a render runs, then the concat listing contains the segment files and the render succeeds (today `_concat_command` always writes an empty listing so every clips render fails)
- [x] Given a media directory that cannot be created, when a faceless render runs, then the experiment is marked render_failed (today the mkdir sits outside the try and escapes as a 500)
