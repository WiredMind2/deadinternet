### US-006: Show why a render failed
**As a** operator, **I want** to see the render error text on a `render_failed` video **so that** I know what to fix before re-rendering.
**Points:** 1
**Status:** Done
**Acceptance criteria:**
- [x] Given a video in `render_failed`, when I select it on Board, then the facts show the stored render error message.
- [x] Given a video in any other status, when I select it, then no render error row appears.

Checked in the browser against a seeded `render_failed` row: selecting it shows "ffmpeg exited 1: unknown codec"; other rows show no error row.
