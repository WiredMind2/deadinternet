### US-004: Show snapshot views on Results
**As a** operator, **I want** Results to show the views recorded in metric snapshots **so that** views sit beside revenue and clicks when I judge a video.
**Points:** 3
**Status:** Ready
**Acceptance criteria:**
- [ ] Given publications with snapshots, when I open Results, then each row shows the sum of each publication's latest snapshot views, served by `GET /results`.
- [ ] Given a video with no snapshots, when I open Results, then views shows 0 and the page renders without error.
- [ ] Given the Vite dev server, when the dashboard calls the API, then `/snapshots` is proxied like the other routes.
