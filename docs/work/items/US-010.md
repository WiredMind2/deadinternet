### US-010: Refuse a conflicting theme or niche re-creation
**As an** operator, **I want** re-adding an existing theme or niche id with different details to be rejected **so that** a typo cannot silently rewrite my catalog.
**Points:** 2
**Status:** Done
**Acceptance criteria:**
- [x] Given theme `money` exists as `Money/en`, when I post `/themes` id `money` name `Cash` language `en`, then the API returns 409 and the stored theme is unchanged
- [x] Given the same theme exists, when I re-post the identical body, then the API returns 200 and stores one theme
- [x] Given niche `war` exists under theme `money`, when I post `/niches` id `war` with a different theme or name, then the API returns 409 and the stored niche is unchanged
