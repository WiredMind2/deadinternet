### US-034: Public read-only click app
**As an** operator, **I want** the `/r/{code}` redirect served by a separate public app that shares the store but exposes no admin routes **so that** clicks can be served to the open internet without exposing the lab's write surface.
**Points:** 3
**Status:** Ready
**Acceptance criteria:**
- [ ] Given the public app process, when any admin route is requested (experiments, results, suggest, and friends), then it returns 404
- [ ] Given the public app, when `/r/{code}` is hit, then the click is logged exactly as the admin app logs it (same store, same counter+log transaction)
- [ ] Given an unknown code, when `/r/{code}` is hit, then the public app returns 404 without leaking store details
- [ ] Given the repo, when the public app is launched, then it runs as its own entrypoint (own process/port), separate from the admin API
