### US-039: Show which legacy codes the migration renamed
**As an** operator, **I want** the upgrade that de-duplicates tracking codes to tell me what it renamed **so that** a published `/r/abc` link I already handed out does not silently start crediting a different row.
**Points:** 1
**Status:** Ready
**Acceptance criteria:**
- [ ] Given the legacy migration, when it renames a duplicate code, then each rename is recorded (settings key or log line) with the old and new code and the row ids
- [ ] Given the dashboard, when renames were recorded, then they are shown once (dismissable), naming the affected experiments
- [ ] Given the Copy link button, when it copies a tracking link, then it always uses the experiment's current (post-migration) code
