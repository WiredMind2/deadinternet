### US-021: Dashboard form input correctness
**As an** operator, **I want** the dashboard's forms to refuse bad input and survive partial failures **so that** I never record a wrong number, store a garbage URL, or silently duplicate drafts.
**Points:** 5
**Status:** Done
**Acceptance criteria:**
- [x] Given a starter-grid build where a later niche fails mid-loop, when the build errors, then the drafts already created are shown without a manual refresh, the failed niche ids are named in the error, and retrying continues with only the remaining niches (today created drafts are invisible and a retry duplicates every succeeded niche)
- [x] Given the Record-views panel with an empty views field, when Save is clicked, then nothing is posted (today `Number("") === 0` posts a 0-view snapshot that clobbers real views)
- [x] Given a post URL that is not http(s), when Save URL is clicked, then the dashboard refuses it client-side with a message (today any non-empty string is stored permanently)
- [x] Given a niche-add that fails mid-loop, when it errors, then earlier niches are visible without a manual refresh
