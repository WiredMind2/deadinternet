### US-009: Gate proposed drafts with vendored hook, caption, and phrase lints
**As a** operator, **I want** proposed drafts checked by local hook-scoring, caption-fold, and stock-phrase lints **so that** weak drafts are repaired before they reach storyboard approval.
**Points:** 5
**Status:** Done
**Note:** Renumbered from the `vendor-ig-tools` worktree's own register, which called this US-001 (see the collisions history in `README.md`). This is the story-level view; the port itself is US-008.
**Acceptance criteria:**
- [x] Given a draft whose hook scores below the floor, when the proposer evaluates it, then the draft is sent for repair citing the hook score
- [x] Given a caption whose visible fold is weak (no hook in the first ~125 characters), when the proposer evaluates it, then the repair feedback names the fold problem
- [x] Given a script or caption containing stock AI phrases, when the proposer evaluates it, then the repair feedback lists the flagged phrases
- [x] Given a draft that passes all three lints, when the proposer evaluates it, then the draft is accepted without repair
- [x] Given the `deadinternet` package test suite, when it runs, then coverage stays at 85% or higher

Verified on main by `tests/test_lint.py` (hook floor, caption fold, stock phrases, strong-draft pass) and the repair-loop test in `tests/test_proposer.py`; full suite 112 passed at 92.62%.
