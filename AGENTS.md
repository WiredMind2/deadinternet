# DeadInternet

Local lab for short vertical video experiments. Backend: FastAPI + SQLite in
`src/deadinternet/`. Dashboard: React + Vite in `web/`. Research and locked
decisions: `research/synthesis.md`. Design docs: `docs/superpowers/specs/`.

## Work register

Stories live in `docs/work/items/` — edit them directly. Before minting an id,
scan `docs/work/items/` and `docs/work/archive/`; ids are stable and never
reused. Index: `docs/work/README.md`. Done is defined in
`docs/work/definition-of-done.md`. Never delete `docs/work/archive/`.
